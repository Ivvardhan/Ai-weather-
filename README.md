# AI Weather App (modAI)

A beautiful, modern, AI-themed weather forecasting models application. It provides real-time atmospheric analysis, hourly predictions, precipitation maps, and officially sourced weather maps for an immersive meteorological experience.

## Features
- **Real-Time Weather Analysis:** Search for any city to get current temperature, humidity, wind, and UV index.
- **AI-Themed Interface:** Enjoy a sleek, animated UI with floating orbs, glassmorphism, and dynamic design.
- **7-Day Forecast & Hourly Trends:** Plan your week with detailed forecasts.
- **Official Satellite Maps:** Links to official meteorological (ISRO/MOSDAC) data.

## Getting Started

Since this is a static frontend application (HTML, CSS, JS), you don't need any complex server setup. 

1. **Clone the repository:**
   ```bash
   git clone <your-repository-url>
   ```
2. **Open the App:**
   Simply open `index.html` in your web browser. No local server is strictly required, although using an extension like *Live Server* in VS Code will give the best experience.

## Technologies Used
- HTML5
- CSS3 (Vanilla, custom properties, glassmorphism)
- JavaScript (Vanilla)
